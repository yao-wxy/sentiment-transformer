项目内容介绍：
手写了一个简易版transformer encoder，没有做任何改进，仅仅是为了理解原理。
用于情感二分类（正/负面）。
自建了1300条数据集。使用结巴分词构建词表，没有使用任何预训练词向量。
手写了清洗数据的管道。两者逻辑相同。代码结构不同。
使用了两种方法，一个是课程学习，一个是混合训练。
课程学习的清洗代码之外，附带了对简单和复杂数据的区分，便于进行分阶段学习。分阶段学习采用先简单后复杂的原则，按照合理比例逐渐改变简单数据与复杂数据的比例。
混合学习的代码只需要清洗文本。
结果表明，课程学习效果更好，对简单词汇识别准确率高。混合学习对简单文本准确率差。
这个结果是合理的。

训练经历：
用混合训练，不到1000条数据。向量维度64，头数为4。val loss0.65左右。删除所有愤怒数据，困难数据消失以后，val loss0.54左右。
改用课程训练，数据分为简单复杂，1300条左右。向量维度64，头数为4，vall loss0.76左右。改用向量维度128，头数8，vall loss降为0.53。
最后用所有1300条数据进行混合训练，向量维度128，头数8，vall loss达到0.49。降为最低。

分析与总结：
向量维度和头数增加代表模型容量的增加，对课程学习效果显著。说明当前数据需要更复杂的网络才能拟合准确。
课程学习的阶段训练集与验证集划分严格，增加了验证集难度，损失值更高，但总体准确率更高。
在当前小模型和小数据集下，由于数据噪声过大，导致难以拟合。尝试课程学习对准确识别简单数据有良好效果。但两种训练策略目前都不能增加对复杂数据的识别能力。说明模型还不能进行逻辑推理等深度加工。需要增加数据质量和数量，适当增加模型容量，或者选用预训练大模型增加准确率。
